You can launch install.bat or do it manually:

Extract the freeglut.dll file from either the x64 or x86 folder, depending on your operating system:
– If you have a 64-bit version of Windows, use the x64 folder.
– If you have a 32-bit version of Windows, use the x86 folder.
Copy the freeglut.dll file into the C:\Windows\System32 folder.

Copy the OpenGL GLUT Project folder into your Visual Studio project templates directory:
C:\Users\username\Documents\Visual Studio 18\Templates\ProjectTemplates
(or to whatever folder is configured as your project templates location).

Launch Visual Studio. The template will now appear when you create a new project.
